# Wi-Fi Audit Tool — مشروع مصدر

أداة تعليمية لفحص محلي وآمن على Android دون Root. تعرض نتائج مسح Wi-Fi التي يسمح بها نظام Android، وتختبر اتصالاً بسيطاً، وتصدر تقرير TXT وJSON.

## تنبيه مهم
- هذه الملفات **مصدر المشروع وليست APK جاهزاً**.
- لم يُختبر هذا المشروع على جهاز فعلي. قد تتطلب قراءة الشبكات القريبة موافقات وقت التشغيل وتفعيل خدمات الموقع، وقد تختلف القيود حسب إصدار Android والشركة المصنّعة.
- لا تُظهر الأداة بيانات مختلقة عندما لا يعيد النظام نتائج.
- لا تتضمن تخمين كلمات مرور، أو deauthentication، أو تجاوز حماية، أو الاتصال بشبكات دون إذن.
- ملفات التقارير تحفظ في مساحة التطبيق الخاصة.

## ملفات المشروع
- `main.py`: واجهة Kivy.
- `scanner.py`: قراءة نتائج Wi-Fi المتاحة للنظام واختبار اتصال TCP بسيط.
- `reporter.py`: حفظ تقارير JSON وTXT.
- `requirements.txt`: اعتماديات Python.
- `buildozer.spec`: إعداد مبدئي لبناء APK.

## بناء APK
Buildozer يحتاج عادةً بيئة Linux مدعومة، لذلك أسهل مسار من الهاتف هو استخدام بيئة بناء سحابية مثل GitHub Actions أو حاسوب Linux. تثبيت `python` و`git` في Termux وحده لا يكفي لبناء APK.

على بيئة Linux متوافقة:
1. ثبّت متطلبات Android وBuildozer وفق الوثائق الرسمية لـ Buildozer.
2. ضع ملفات المشروع داخل مجلد واحد.
3. نفّذ `buildozer android debug`.
4. ابحث عن APK داخل مجلد `bin/`.

لا ترفع مفاتيح أو كلمات مرور إلى مستودع عام. راجع الأذونات قبل تثبيت أي APK.
